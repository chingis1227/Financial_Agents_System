# Crypto AGENT Workflow Route Card

Status: Runtime route card
Authority: Subordinate to `workflows/crypto_full_cycle.md` and canonical implementation documents.

## Trigger

Use for BTC, ETH, tokens, crypto-linked vehicles, custody/vehicle questions, crypto allocation, or crypto market setup over a stated horizon.

## Required first action

Ask exactly 5 crypto questions in one block and wait.

## Required modules

- evidence collection and freshness check
- crypto asset analysis
- macro/liquidity context
- adoption, liquidity, network, tokenomics, custody, and regulation where material
- valuation / expectations equivalent
- positioning, news, and market sense when material
- risk / red-team review
- portfolio fit / limited portfolio fit
- IC synthesis

## Allowed output

Saved `investment_report.md` plus `audit/`, or gate-aware Limited / Blocked artifact.

## Forbidden output

No final IC Action without custody/vehicle, evidence, risk, valuation-equivalent, and portfolio gates.

## Downgrade rules

If the user requests yield, staking, leverage, custody, or complex crypto products, apply complex product gate and constrain status.

## Validation expectations

BTC 3-year investment prompt must map to crypto AGENT workflow and require 5 questions.
